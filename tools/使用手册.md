# 泡泡哥雾化 · 使用手册

本文档分三部分：

1. **项目文件介绍**：每个文件夹是做什么的
2. **从 0 到 1**：新电脑第一次怎么跑起来
3. **用户手册**：商品管理工具怎么用、怎么打包、怎么发布

> 适用对象：泡泡哥本人、运营、帮忙改商品的人。
> 不需要懂代码，按步骤操作即可。

---

### 哪些文件可以改

| 想改什么 | 改哪里 |
| --- | --- |
| 商品、价格、描述、图片 | 用工具改，自动写 `src/data/sections/*.json` 和 `public/images/products/` |
| 分类、导航、排序 | 用工具「分类 / 导航」页签，写 `src/data/site/categories.json` |
| 微信二维码、QQ | 用工具「站点设置」，或改 `src/data/site/contacts.json` |
| 公告、包邮门槛、运费 | 用工具「站点设置」，或改 `src/data/site/general.json` |
| 页脚链接 | `src/data/site/footer.json` |
| 帮助页文案 | `src/data/site/info-pages.json` |
| 颜色、字体、布局 | `src/assets/styles/main.css` |

### 哪些文件不要手动改

- `src/data/index.js`：自动加载数据、生成导航
- `src/router/`、`src/views/`、`src/components/`：页面代码
- `dist/`、`node_modules/`：自动生成
- `tools/build/`、`tools/dist/`：打包产物

## 二、从 0 到 1（新电脑第一次）

### 第 1 步：安装环境

只改商品、不发布：只需要 **Python**。
要本地预览网站：需要 **Node.js**。
要发布上线：需要 **Git**。

| 软件 | 版本 | 下载 | 注意 |
| --- | --- | --- | --- |
| Python | 3.10 或更高 | https://www.python.org/downloads/ | 安装时勾选 **Add python.exe to PATH** |
| Node.js | 18 / 20 LTS | https://nodejs.org/ | 一路下一步 |
| Git | 最新版 | https://git-scm.com/ | 默认选项即可 |

安装完打开 PowerShell，检查：

```powershell
python --version
node --version
npm --version
git --version
```

都能输出版本号就说明装好了。

### 第 2 步：拿到项目

两种情况：

- **拷贝文件夹**：把整个 `vip9009` 文件夹复制到电脑上，例如 `C:\vip9009`
- **克隆仓库**：

```powershell
git clone https://github.com/vip9009/vip9009.git
cd vip9009
```

> 如果 `github.com:443` 连不上，改用 SSH over 443，见「七、发布到 GitHub」。

### 第 3 步：安装依赖

```powershell
cd C:\vip9009
python -m pip install -r tools\requirements.txt
npm install
```

如果只使用打包好的 exe，可以跳过这两步。

### 第 4 步：启动商品管理工具

方式一（有 Python）：

```text
双击 tools\启动商品管理工具.bat
```

方式二（免 Python，推荐发给别人）：

```text
双击 tools\dist\泡泡哥商品管理工具.exe
```

方式三（命令行）：

```powershell
python tools\product_admin.py
```

### 第 5 步：本地预览网站（可选）

```powershell
npm run dev
```

浏览器打开终端提示的地址，一般是 `http://localhost:5173/`。

生产构建：

```powershell
npm run build
npm run preview
```

### 第 6 步：添加真实商品并发布

1. 工具里新增商品、分类、图片
2. 点「保存商品」
3. 点右上角「发布到 GitHub」
4. 等 1–3 分钟，刷新线上地址

## 三、用户手册（商品管理工具）

### 3.1 界面说明

| 区域 | 作用 |
| --- | --- |
| 商品管理 | 新增、修改、删除、排序商品；编辑图文/视频详情 |
| 分类 / 导航 | 管理一级分类、二级分类和顶部导航 |
| 站点设置 | 公告、首页 Banner 链接、包邮门槛、客服微信名称/头像/二维码、QQ |
| 发布到 GitHub | 提交数据并推送，自动部署 |
| 初始化数据 | 清空全部商品和商品图片，保留分类；清空前自动备份 |
| 打开数据目录 | 打开 `src/data` |
| 导出数据包 | 没有 Git 时，导出 zip 拷回主电脑 |
| 使用说明 | 打开本文档 |

### 3.2 商品管理

#### 新增商品

1. 点「新增商品」
2. 选择**一级分类**（例如「一次性电子烟」）
3. 选择**二级分类**（例如「悦刻一次性电子烟」）
4. 填商品名称、价格
5. 点「选择图片」，从电脑任意位置选图
6. 填商品描述（可换行）
7. 点「保存商品」

#### 修改商品

左侧列表选中商品 → 右侧修改 → 「保存商品」。

#### 删除商品

选中商品 → 「删除商品」。

#### 排序

选中商品 → 「上移 / 下移」。前台顺序同步。

#### 搜索和筛选

- 顶部搜索框：按商品名称、品牌、分类、口味、标签搜索
- 分类筛选：可以选一级，也可以选到「一级 / 二级」末级分类
- 商品列表会显示品牌和状态；无货商品整行变红，方便快速检查

#### 图片规则

- 可以从任意文件夹选图（桌面、下载、U 盘都行）
- 保存时自动压缩成 800px WebP
- 自动复制到 `public\images\products\`
- 自动命名：`一级分类ID-时间戳.webp`
- 原图不会进项目，建议原图单独放 `桌面\泡泡哥商品原图\`

#### 更多信息（品牌 / 角标 / 口味 / 参数）

点商品表单里的「更多信息」，可以设置：

| 字段 | 作用 |
| --- | --- |
| 品牌 | 从站点固定品牌列表选择（`general.json` 的 `brands`）；现有商品已经在用的品牌也会自动出现在列表里，保证前台 Logo、品牌链接匹配 |
| 角标 / 标签 | 从常用标签列表多选；活动角标显示图片右上（HOT、上新、5盒赠主机），自定义/呼吸灯/凉度调节等功能标签显示图片左下。列表没有的可写到“额外标签” |
| 价格上限 | 显示价格区间，例如 `¥138 – ¥198` |
| 库存状态 | 单选“现货 / 无货”；选“无货”后卡片显示“无货”，不能购买 |
| HOT 角标 | 单选“显示 / 不显示”，控制卡片 HOT 标记 |
| 店长推荐 | 单选“显示 / 不显示”，自动显示“店长推荐”标签 |
| 口味 / 规格 | 每行一个；需要单独价格时写 `名称|价格`；该口味无货写 `名称|价格|无货`。选中后显示对应价格，无货口味购买按钮置灰 |
| 参数 | 每行一个 `键|值`，显示在商品页“参数”Tab |

改完点弹窗里的「保存」，再点主界面的「保存商品」。

#### 图文 / 视频详情

商品表单里点「图文/视频详情」，可以按顺序添加：

- 文字段落（支持换行）
- 小标题
- 多张详情图片
- 视频（本地 MP4 / WebM，或填写视频网址）

操作方式：

1. 点「添加文字」写正文；弹窗里选择“小标题（加粗显示）”就会显示成加粗标题
2. 点「添加图片」可以一次选多张，自动压缩到 1600px WebP，保存到 `public/images/details/`
3. 点「添加视频」选本地 MP4 / WebM，原样复制到 `public/videos/products/`；没有本地文件时也可以填 https 视频地址
4. 选中内容块后可以「编辑」说明文字、「上移 / 下移」调整顺序、「删除」
5. 点「保存详情内容」，再点主界面的「保存商品」

> 视频建议控制在 60MB 以内、30 秒左右，太大会让网站和分发包变慢。
> 不要填写 `vapepu.com` 或 `wp-content` 的图片/视频地址；请先把素材下载到本地再上传。
> 有图文详情时，商品详情页优先显示图文详情；没有时继续显示原来的纯文本描述。

#### 描述显示在哪

- 商品卡显示：品牌、角标、名称、价格、口味下拉 / 查看详情
- 商品描述只显示在**商品详情页**
- 不填描述时，详情页使用默认文案

### 3.3 分类 / 导航

- **一级分类** = 顶部导航菜单
- **二级分类** = 下拉菜单项
- 导航由分类数据自动生成，不需要改代码

#### 新增一级分类

「分类 / 导航」→「新增一级分类」→ 填 ID、名称、排序 → 保存。

ID 只能用小写字母、数字、短横线，例如 `new-pods`。保存后会自动创建同名商品分区。

#### 新增二级分类

先选中一级分类 → 「新增二级分类」→ 填 ID、名称 → 保存。

#### 修改 / 排序 / 隐藏

选中分类 → 改名称、描述、排序 → 保存。

- 排序数字越小越靠前
- 「顶部导航」选择「隐藏」可隐藏一级菜单
- 二级分类不能单独隐藏，删掉即可

#### 删除规则

- 删除一级分类前，先删除它的二级分类
- 删除二级分类前，先把商品移到其它分类
- 「热门产品」是首页核心分类，不能删除

### 3.4 保存 vs 发布

| 操作 | 结果 |
| --- | --- |
| 保存商品 / 保存分类 | 只写本地 JSON，线上不变 |
| 发布到 GitHub | 提交 `src/data` + 商品图片并 push，线上更新 |

发布前如果表单有未保存的修改，工具会提醒你先保存。

### 3.5 没有 Git 的电脑

可以正常改、正常保存，不能直接发布：

1. 点「导出数据包」
2. 生成 zip（包含 `src/data`、商品图片、客服头像/二维码）
3. 把 zip 拷到有 Git 的主电脑
4. 解压覆盖到项目根目录
5. 打开工具点「发布到 GitHub」

### 3.6 初始化数据

用于正式上架前清空测试数据。点「商品管理」右上角的红色「初始化数据」按钮：

- 删除全部商品
- 删除 `public/images/products/` 里的商品图片
- 删除 `public/images/details/` 里的详情图片
- 删除 `public/videos/products/` 里的详情视频
- 保留一级/二级分类、导航、品牌信息、微信二维码、QQ
- 清空前自动备份到 `tools\.backups\reset-时间.zip`
- 不会自动发布，线上要等点「发布到 GitHub」才更新

恢复备份：把该 zip 解压并覆盖到项目根目录。

### 3.7 发给别人使用

不要只发 exe，exe 需要项目数据。正确做法：

```powershell
python tools\make_package.py
```

会在桌面生成 `泡泡哥商品管理工具-发给别人-时间.zip`，包含：

```text
泡泡哥商品管理工具\
├─ 泡泡哥商品管理工具.exe
├─ 使用手册.md
├─ 使用说明.txt
├─ src\data\
├─ public\images\products\
├─ public\images\details\
├─ public\videos\products\
└─ public\images\（客服头像、微信二维码）
```

对方解压后双击 exe 即可，不需要 Python / Node / Git。

### 3.8 站点设置

「站点设置」页签可以改：

- 公告文字、公告右侧提示
- 首页 Banner 点击链接
- 包邮门槛、运费
- 客服微信名称、微信说明
- 微信头像（`public/images/wechat-avatar.webp`）
- 客服微信二维码（`public/images/wechat-qr.webp`）
- 客服 QQ

页面上会预览微信头像和微信二维码，确认图片没选错再保存。

改完点「保存站点设置」，再点右上角「发布到 GitHub」。

> 当前项目里的微信二维码是占位图（`paopao-qr.png`），正式使用前请在「站点设置」里换成客服微信二维码。
> 站点不提供在线支付，也不配置收款码；客户通过微信 / QQ 联系客服确认付款方式。

## 四、数据文件说明

### 4.1 商品分区 `src/data/sections/*.json`

```json
{
  "id": "disposables",
  "title": "一次性电子烟",
  "sort": 2,
  "products": [
    {
      "title": "商品名称",
      "price": 288,
      "imageAlt": "商品名称",
      "localImage": "/images/products/disposables-20261126144154772861.webp",
      "subcategory": "relx-disposable",
      "description": "可选：详情页描述",
      "detailBlocks": [
        { "type": "heading", "text": "产品细节" },
        { "type": "text", "text": "支持换行的文字段落" },
        { "type": "image", "src": "/images/details/detail-1.webp", "caption": "实拍图" },
        { "type": "video", "src": "/videos/products/video-1.mp4" }
      ]
    }
  ]
}
```

- `sort`：首页分区顺序
- `localImage`：`public` 下的路径
- `subcategory`：二级分类 ID，可留空
- `description`：可留空，留空用默认文案
- `detailBlocks`：图文/视频详情块，类型支持 `text`、`heading`、`image`、`video`；有值时优先于 `description` 显示

### 4.2 分类与导航 `src/data/site/categories.json`

```json
{
  "disposables": {
    "title": "一次性电子烟",
    "desc": "分类描述",
    "section": "disposables",
    "sort": 1,
    "nav": true,
    "children": ["relx-disposable"]
  },
  "relx-disposable": {
    "title": "悦刻一次性电子烟",
    "desc": "二级分类描述",
    "parent": "disposables",
    "sort": 1
  },
  "contact": {
    "title": "联系客服",
    "to": "/contact",
    "nav": true,
    "sort": 99
  }
}
```

- 一级分类用 `section` 关联商品分区
- 二级分类用 `parent` 关联一级分类
- `nav: false` 不在顶部导航显示
- `to` 用于非商品菜单

### 4.3 联系方式 `src/data/site/contacts.json`

微信头像、微信二维码、QQ 号。QQ 只展示，不跳转。头像和二维码可以直接在工具「站点设置」里上传，不用手改 JSON。

## 五、打包命令

### 5.1 打包网站

```powershell
cd C:\vip9009
npm install
npm run build
```

产物在 `dist/`，可直接部署到任意静态服务器。

本地预览：

```powershell
npm run preview
```

### 5.2 打包 exe（免 Python）

```powershell
cd C:\vip9009
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --clean --onefile --windowed `
  --name "泡泡哥商品管理工具" `
  --icon "tools\app.ico" `
  --distpath "tools\dist" `
  --workpath "tools\build" `
  --specpath "." `
  "tools\product_admin.py"
```

或者直接双击：

```text
tools\build_exe.bat
```

产物：

```text
tools\dist\泡泡哥商品管理工具.exe
```

注意：

- exe 约 25MB
- 必须放在项目文件夹里，否则提示「找不到项目数据」
- exe 不提交 Git（`.gitignore` 已忽略）
- 工具代码更新后要重新打包

### 5.3 打包“发给别人”的 zip

```powershell
python tools\make_package.py
```

默认输出到桌面，包含 exe、数据、图片、使用手册。

指定输出位置：

```powershell
python tools\make_package.py --output D:\paopao-tool.zip
```

### 5.4 备份数据

用工具改之前建议先备份：

```powershell
Compress-Archive -Path src\data, public\images\products `
  -DestinationPath "$env:USERPROFILE\Desktop\paopao-backup.zip" -Force
```

工具每次保存也会自动备份 JSON 到 `tools\.backups\`（不提交 Git）。

恢复：把备份 zip 解压覆盖到项目根目录。

## 六、日常操作 checklist

### 新增一个商品

- [ ] 选对一级分类
- [ ] 选对二级分类（末级）
- [ ] 名称、价格正确
- [ ] 图片清晰，比例接近 4:3
- [ ] 描述可选
- [ ] 点「保存商品」
- [ ] 全部改完点「发布到 GitHub」

### 上线前检查

- [ ] 没有「测试」商品
- [ ] 价格都大于 0，没有空值
- [ ] 每张图片都能显示

## 七、发布到 GitHub

### 7.1 首次配置

```powershell
git remote -v
git remote set-url origin ssh://git@ssh.github.com:443/vip9009/vip9009.git
```

生成 SSH key（如果还没有）：

```powershell
ssh-keygen -t rsa -b 4096 -C "vip9009"
```

把 `C:\Users\<用户名>\.ssh\id_rsa.pub` 的内容加到：

```text
https://github.com/settings/keys
```

测试：

```powershell
ssh -T -p 443 git@ssh.github.com
```

成功会显示 `Hi vip9009! You've successfully authenticated`。

### 7.2 推送

工具里点「发布到 GitHub」即可，也可以手动：

```powershell
git add src/data public/images/products
git commit -m "更新商品数据"
git push
```

### 7.3 GitHub Pages 设置

1. 打开仓库 **Settings → Pages**
2. **Source** 选择 **GitHub Actions**
3. 打开 **Actions**，确认 `Deploy to GitHub Pages` 成功
4. 访问：

```text
https://vip9009.github.io/vip9009/
```

> 不要选 Jekyll 或 Static HTML 模板，项目的 `.github/workflows/deploy.yml` 已经配好。

## 八、常见问题

### 双击 bat 一闪而过

- 确认文件是 CRLF 换行（仓库里的版本已修复）
- 用命令行运行看报错：

```powershell
cd C:\vip9009
tools\启动商品管理工具.bat
```

- 或者直接用 exe

### 提示缺少 Pillow

```powershell
python -m pip install -r tools\requirements.txt
```

### 提示「找不到项目数据」

exe 被移出项目文件夹了。把 exe 放回 `tools\dist\`，并确保同级的项目里有 `src\data`。

### 点发布提示「没有 Git」

这台电脑没装 Git。改完点「导出数据包」，拷回主电脑发布。

### 推送报 `Permission denied (publickey)`

SSH 公钥没加到 GitHub，或加到了别的账号。重新检查：

```powershell
ssh -T -p 443 git@ssh.github.com
```

### 保存后线上没变化

- 只点了保存，没点发布
- Actions 还在跑，等 1–3 分钟
- 浏览器缓存，强制刷新

### 点了初始化，线上还有商品

初始化只清空本地数据，不会自动发布。点「发布到 GitHub」后，线上才会一起清空。

### 新增一级分类后本地看不到

重启 `npm run dev`，Vite 需要重新加载新的分区 JSON。线上构建不受影响。

### 图片预览很小 / 看不到

确认工具已更新到最新版本；预览区固定 210px 高。

### Windows 提示未知发布者

exe 没有代码签名，点「更多信息 → 仍要运行」。

### 工具改了数据，但线上还是旧的

工具会提交 `src/data`、`public/images/products` 和工具里上传的微信头像/二维码图片。如果改了代码、样式，需要另外提交源码。
